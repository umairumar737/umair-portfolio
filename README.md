# Umair Portfolio

Premium single-page portfolio prepared for Vercel Drop.

## Deploy
1. Go to https://vercel.com/drop
2. Drag `umair-portfolio.zip` into the page.
3. Choose your Vercel team/project name.
4. Deploy.

The project is intentionally static (HTML/CSS/JS), so Vercel can serve it without a build step.

## Before going live
Replace the placeholder email `hello@umair.dev` and generic LinkedIn/GitHub URLs with Umair's real contact/social links.

Project links included:
- Vine Taxis: https://vinetaxis.com/
- Celine Furnishings: https://celinefurnishings.co.uk/
- The Book Mart: https://thebookmart.pk/
- BitsGroove is presented as a portfolio case study without an unverified external URL.
